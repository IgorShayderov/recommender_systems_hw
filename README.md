# Книжная рекомендательная система

Учебный проект по построению и сравнению рекомендательных систем для книг на датасете [Goodbooks-10k](https://www.kaggle.com/datasets/zygmunt/goodbooks-10k). Реализованы неперсонализированная, контентная и коллаборативные модели, проведён разведочный анализ данных (EDA) и выполнено сравнение качества рекомендаций.
Вся реализация и результаты экспериментов находятся в ноутбуке **[`hw.ipynb`](hw.ipynb)**.
